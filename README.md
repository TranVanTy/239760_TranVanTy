
# Hệ thống quản lý nhân sự trên nền tảng đám mây
## Thông tin sinh viên
- Họ tên: Trần Văn Tý
- MSSV: 239760
- Lớp: DH23TIN10

## Mô tả
Xây dựng hệ thống quản lý nhân sự cho phép xem, thêm,
tìm kiếm, cập nhật và xóa hồ sơ nhân viên.
Dữ liệu được lưu trên MongoDB Atlas.

## Công nghệ
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Source control: Git, GitHub
- Container: Docker, Docker Hub
- Deployment: Render
